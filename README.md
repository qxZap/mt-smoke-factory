# Smoke Factory

Plugin to cause more tire smoke.

Burnouts and drifts leave a real cloud: tire smoke lasts longer, spreads wider and rises.

Settings: `Binaries\Win64\smoke_factory.ini`, section `[Smoke]`. Purely visual and local.

## Install

Needs [Plugin Loader](https://github.com/qxZap/mt-plugin-loader) (`version.dll`) in
`MotorTown\Binaries\Win64\`. Put `mt_plugin_SmokeFactory.dll` in `MotorTown\Binaries\Win64\plugins\`.

## Build

`build.bat` (MSVC 2022, x64) writes `out\mt_plugin_SmokeFactory.dll`.
